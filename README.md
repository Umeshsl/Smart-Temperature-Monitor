# 🌡️ Smart Temperature Monitor

## 📌 About the Project

Smart Temperature Monitor is a simple Python-based project that monitors
temperature and provides an alert when the temperature exceeds a predefined
threshold.

This project demonstrates basic Python programming, conditional statements,
user input handling, and Git/GitHub version control.

## 🚀 Features

- 🌡️ Temperature input in Celsius
- 📊 Temperature monitoring
- ⚠️ High-temperature warning
- ✅ Normal-temperature indication
- 💻 Simple command-line interface

## 🛠️ Technologies Used

- Python
- Visual Studio Code
- Git
- GitHub

## ⚙️ How It Works

1. The user enters the temperature in Celsius.
2. The program checks whether the temperature is greater than 35°C.
3. If the temperature is above 35°C, a high-temperature warning is displayed.
4. Otherwise, the program displays that the temperature is normal.
